One resident in Vacaville

This page follows one resident in Vacaville, California.

The groups are the different ways a tax reaches them.

Each tax has three document slots: Defined, Collected, and Spent.

Most slots are empty.

That emptiness is the point.

As a stack

The length is only so the stack can be seen.

It is not revenue and it is not a rate.

A stub is marked with the word Stub, an amber edge, and a hatch.

An inventory record has an indigo edge and a link, and the word Stub is absent.

One stub still links to a use-tax record, because the sales-tax stack is not that record.

Each slab has three pips: Defined, Collected, and Spent.

A filled pip means a document URL is on file.

An empty pip means none yet.
